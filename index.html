Watch Bilibili in Your Own Language

A Chrome/Edge extension that adds real-time multi-language subtitles to Bilibili videos using Google Translate. Fire-and-forget translation that just works!

Install Extension Source Code

⚠️ BiliSub Requirements

BiliSub requires AI-Generated Chinese (AI-Zh) subtitles to translate. This extension automatically detects and enables the ai-zh or zh-CN subtitle track from Bilibili videos. If a video does not have these, translation will not activate.

Project Origins & Inspiration

BiliSub is designed with a high focus on performance and minimal overhead, standing on the shoulders of two phenomenal open-source projects:

  • Bilibili Double Subtitle — Core foundation. The dual-subtitle architecture, player subtitle detection mechanism, and Bilibili API integration are adopted from this project as the base.
  • Immersive Translation — Realtime tuning reference. High-precision translation concepts, zero-lag approach, and immersive UX were studied from this project then adapted for Bilibili use case precision.

Technical Details

BiliSub uses a "UDP-style" pipeline designed to keep translating no matter what.

1. Bilibili Player

Video starts playback, injection interceptor activates.

2. Track Detector

Locates and captures AI-generated Chinese (ai-zh) track.

3. Translate Request

Sends lines to Google Translate API asynchronously.

4. Inject Subtitles

Outputs translation elegantly in dual or full mode.

Manual Installation

Get the developer extension running in chromium browser under a minute.

STEP 01

Clone Repository

Download the lightweight source code files to your desktop.

git clone https://github.com/fazza-abiyyu/BiliSub-Translator.git
STEP 02

Open Extensions Settings

Copy and paste this URL into your browser tab address bar:

chrome://extensions/
STEP 03

Toggle Developer Mode

Locate the "Developer mode" switch in the upper-right corner of the Extensions panel and turn it ON.

STEP 04

Load Unpacked Folder

Click the "Load unpacked" action button in top-left, and select the folder you cloned or downloaded from step 1.

Note for Edge users: Same as Chrome, open edge://extensions/ in your Edge browser tab address bar and follow the exact same steps.
