A seamless browser extension that adds real-time multi-language subtitles to Bilibili videos. No API keys needed, just install and watch.

Install Extension Source Code

Requirement: Videos need AI subtitles. The extension prefers ai-zh/ai-cn (AI Chinese), and automatically falls back to ai-en (AI English) when no Chinese track exists.

Install in 30 Seconds

Load it manually into Chrome, Edge or Firefox.

1

Clone Repository

Download the extension files to your computer.

git clone https://github.com/fazza-abiyyu/BiliSub-Translator.git
2

Open Extensions Page

Paste this into your browser's address bar.

chrome://extensions/
3

Enable & Load

Turn on Developer Mode (usually top right). Then click Load unpacked and select the downloaded BiliSub-Translator folder. You're done!
