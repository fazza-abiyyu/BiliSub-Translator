Notes to reviewer

Thank you for reviewing BiliSub v1.0.4.

Build reproducibility:
  Source of truth manifest is manifest.json at the project root (Chromium-style MV3, service_worker only).
  A single Python script produces exact, browser-specific packages:
    python3 scripts/build.py          # build Firefox XPI + Edge/Chrome ZIP
    python3 scripts/build.py firefox  # Firefox only
    python3 scripts/build.py edge     # Edge only

  The script copies every listed file into a temp directory, patches the manifest per target, and zips it.
  Firefox patch adds: background.scripts fallback + browser_specific_settings.gecko (id, strict_min_version, data_collection_permissions).
  Edge/Chrome patch: none — base manifest is already MV3-compliant.

  Expected output artifacts (identical content to the attached submission):
    Out/bilisub-firefox-1.0.4.xpi
    Out/bilisub-edge-1.0.4.zip

Security / AMO notes:
  - No eval(), no Function(), no remote code loading.
  - All dynamically-inserted DOM uses DOMParser + DocumentFragment (parseHTML helper) — zero innerHTML assignment on runtime content.
  - Translation routing goes through background.js (isolated world) to bypass CORS; no requests from content script.
  - Minimal host_permissions: only Bilibili, translation backends (Google/Lingva/Mymemory), and CDN (hdslb.com).

About this release (v1.0.4):
  The functional change is limited to content.js lines ~1090–1405, refactoring the hover-based translate trigger to a selection-based trigger.
  No new permissions, no new network calls, no new storage keys.
